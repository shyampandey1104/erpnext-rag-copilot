# 🤖 ERPNext RAG AI Knowledge Copilot

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![ERPNext](https://img.shields.io/badge/ERPNext-v14%20%7C%20v15-blue.svg)](https://erpnext.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A natural language **AI Copilot & Query Assistant** for **ERPNext**. Allows non-technical business users and executives to ask questions in plain English or Hindi and automatically generates structured Frappe REST API queries to answer questions with real-time numbers.

---

## ⚡ Highlights
- 💬 **Natural Language to Frappe Query**: Translates conversational questions into DocType filters.
- 📊 **Instant Financial Aggregations**: Sums outstanding balances, lists pending orders, and counts active leads.
- 🧪 **Unit Tests**: Full pytest test suite included.
